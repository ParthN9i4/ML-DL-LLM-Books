# Weekly paper analyses

One file per paper, `weekNN-shortname.md`, drafted by a weekly automation and then
corrected by hand. The queue and the nine-point template live in `../study-plan.html`.

The contract for every file here:

- Extractions follow the nine-point template **in order**. A paper that does not report
  something gets an explicit "not reported", never a guess.
- **Point 8 (the claim you would attack) is never machine-drafted.** The automation
  leaves it as `_(yours to write)_`. If a draft ever contains a filled-in point 8,
  treat the whole draft with suspicion.
- Every number in a draft carries a location tag (section/table of the paper) so it can
  be checked in seconds. A number without a location is treated as unverified.
- The draft is a hypothesis; the reading is the test. Correct the file in place and
  commit — the git history of each file is the record of what the automation got wrong,
  which is itself useful calibration data.

`comparison-table.md` holds one row per paper (columns 1–7 only) and is the actual
deliverable of the 40-week track.
